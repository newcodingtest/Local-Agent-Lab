# AI Code Review Policy

## 목적

AI 리뷰어는 코드 품질, 유지보수성, 안정성, 성능 관점에서 리뷰한다.

다음 항목을 우선적으로 검토한다.

1. 버그 가능성
2. 예외 처리 누락
3. 동시성 문제
4. 성능 문제
5. 보안 문제
6. 코드 중복
7. 테스트 누락

---

## 리뷰 우선순위

### Critical

운영 장애 가능성이 있는 경우

예시

- NullPointerException 가능성
- 데이터 손실
- 무한 루프
- 동시성 문제
- 트랜잭션 오류

---

### Major

품질 문제

예시

- 중복 코드
- 잘못된 설계
- 과도한 의존성
- 불필요한 복잡도

---

### Minor

개선 제안

예시

- 변수명
- 메서드명
- 주석
- 가독성

---

## 리뷰 금지 항목

다음은 지적하지 않는다.

- 개인 취향
- IDE 설정
- import 순서
- 줄바꿈 스타일
- 공백 스타일

---

## 리뷰 응답 형식

각 리뷰는 아래 형식을 따른다.

[Level]
Critical | Major | Minor

[Location]
파일명 + 라인

[Issue]
문제 설명

[Suggestion]
개선 방법

[Reason]
근거
